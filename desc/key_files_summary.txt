Tier 1: 启动和初始化 (MUST READ FIRST)
═════════════════════════════════════════════════════════════════════════════════

📄 /index.ts
用途: 项目主入口
核心导出: initializeServerAsync()
关键行为:
- 导入 initializeServerAsync from app/app.js
- 异步初始化服务器
- 处理启动错误
重要: 这是服务启动的第一行代码

📄 /app/app.ts
用途: Express 应用创建和整体初始化
核心导出:
- createAppAsync(config) - Express app 创建
- initializeServerAsync() - 完整服务器初始化
关键流程:
1. 加载配置 (getConfig)
2. 初始化 DI 容器 (initializeGlobalContainer)
3. 创建 Express 应用
4. 应用中间件
5. 配置 Socket.IO
6. 启动 HTTP 服务器
重要: 核心业务流程的协调者

📄 /app/config.ts & /app/config/*
用途: 配置管理和加载
文件清单:
- config-loader.ts - 配置加载器
- config-processor.ts - 配置处理
- default-config.ts - 默认配置
- env-parser.ts - 环境变量解析
- config-schema.ts - 配置验证模式
核心: 从环境变量、配置文件加载应用配置

📄 /app/server.ts
用途: HTTP 服务器创建和启动
核心函数:
- createServer(app) - 创建 HTTP 服务器
- startServer(server, config) - 启动监听
重要: 网络通信的基础层

Tier 2: WebSocket 和 Socket.IO 配置
═════════════════════════════════════════════════════════════════════════════════

📄 /app/io.ts
用途: Socket.IO 服务器配置
核心函数:
- configureSocketIO(server, sessionMiddleware, config) - SSH Socket.IO
- configureTelnetNamespace(server, sessionMiddleware, config) - Telnet
功能:
- 配置 CORS
- 整合会话中间件
- 设置 ping 参数
重要: Socket.IO 配置的中心点

📄 /app/socket-v2.ts
用途: Socket.IO 连接处理初始化
核心导出: default export (init 函数)
签名: init(io, config, services, protocol)
关键行为:
- 监听 'connection' 事件
- 为每个连接创建 ServiceSocketAdapter
流程: Socket 连接 → ServiceSocketAdapter 创建 → 事件处理器设置

Tier 3: HTTP 路由和请求处理
═════════════════════════════════════════════════════════════════════════════════

📄 /app/routes/routes-v2.ts
用途: Express 路由定义
核心导出: createRoutesV2(config) → Router
路由定义:
- GET /ssh - SSH 登录页
- GET /ssh/:host - 直接连接主机
- GET /ssh/:host/:port - 指定端口连接
- POST /ssh - POST 认证处理
- GET /ssh/config - 获取 SSH 配置
- GET /host/:host, /host/:host/:port - 自动连接
重要: 定义所有 HTTP 端点

📄 /app/connectionHandler.ts
用途: HTTP 连接处理（HTML 模板渲染）
核心导出: default export (handleConnection 函数)
签名: handleConnection(req, res, opts) → Promise<void>
关键功能:
- 读取 client.htm 模板
- 将配置注入 HTML
- 返回渲染后的 HTML 给浏览器
重要: 客户端 HTML 的生成点

📄 /app/routes/handlers/ssh-handler.ts
用途: SSH 路由处理逻辑（纯函数）
导出的主要函数:
- validateSshRouteCredentials(creds) - 验证凭证
- processPostAuthRequest(body, query, config) - 处理 POST 认证
- createAuthSessionUpdates(creds, conn) - 创建会话更新
- validateConnectionParameters(params) - 验证连接参数
- sanitizeCredentialsForLogging(creds) - 清理日志

📄 /app/routes/handlers/ssh-config-handler.ts
用途: SSH 配置响应生成
核心导出: createSshConfigResponse()
功能: 返回 SSH 配置给客户端

📄 /app/routes/adapters/express-adapter.ts
用途: Express 框架适配层
导出的适配函数:
- createRouteHandler() - 同步路由处理
- asyncRouteHandler() - 异步路由处理
- createErrorHandler() - 错误处理

Tier 4: Socket 事件处理（核心业务逻辑）
═════════════════════════════════════════════════════════════════════════════════

📄 /app/socket/adapters/service-socket-adapter.ts ⭐️ 非常重要
用途: Socket.IO 主适配器，协调所有事件处理
核心类: ServiceSocketAdapter
构造函数参数: (socket, config, services, protocol='ssh')
内部组件:
- authPipeline: UnifiedAuthPipeline
- auth: ServiceSocketAuthentication
- terminal: ServiceSocketTerminal
- sftp: ServiceSocketSftp
- control: ServiceSocketControl
- prompt: ServiceSocketPrompt
关键方法:
- setupEventHandlers() - 设置所有 Socket 事件监听
- logSessionInit() - 记录会话初始化
- emitHostKeyVerificationConfig() - 发送主机密钥验证配置
流程: 每个 Socket 连接一个适配器实例

📄 /app/socket/adapters/service-socket-authentication.ts
用途: 认证事件处理
核心类: ServiceSocketAuthentication
关键方法:
- checkInitialAuth() - 检查初始认证状态
- requestAuthentication() - 请求认证
- requestKeyboardInteractiveAuth() - 请求键盘交互认证
- handleAuthentication(credentials) - 处理认证请求
- handleKeyboardInteractiveResponse(responses) - 处理键盘交互响应
- handleSSHKeyboardInteractive() - 处理 SSH 键盘交互提示
事件:
- 监听: 'authenticate' (AUTH)
- 发送: 'authentication' (AUTH_SUCCESS), 'connection-error'

📄 /app/socket/adapters/service-socket-terminal.ts
用途: 终端事件处理
核心类: ServiceSocketTerminal
关键方法:
- handleTerminal(settings) - 创建终端/shell
- handleResize(dimensions) - 调整终端大小
- handleData(data) - 处理用户输入
- handleExec(request) - 执行 SSH 命令
事件:
- 监听: 'terminal', 'resize', 'data', 'exec'
- 发送: 'data' (SSH 输出), 'ssherror'
流程: 建立双向数据流 (Browser ←→ SSH Server)

📄 /app/socket/adapters/service-socket-sftp.ts
用途: SFTP 文件传输事件处理
核心类: ServiceSocketSftp
支持的操作: 列表、查询属性、创建目录、删除、上传、下载
事件:
- 监听: 'sftp-list', 'sftp-upload-start', etc.
- 发送: 'sftp-directory', 'sftp-upload-ready', etc.

📄 /app/socket/adapters/service-socket-control.ts
用途: 控制消息处理
核心类: ServiceSocketControl
处理消息类型: close, keepalive, debug 等

📄 /app/socket/adapters/service-socket-prompt.ts
用途: 提示系统处理
核心类: ServiceSocketPrompt
支持的提示类型: input, confirm, notice, toast
事件:
- 监听: 'prompt-response'
- 发送: 'prompt'

📄 /app/constants/socket-events.ts
用途: Socket 事件常量定义
关键常量: SOCKET_EVENTS 对象
包含所有客户端→服务器和服务器→客户端事件名称
重要: Socket 事件的单一来源

📄 /app/services/ssh/ssh-service.ts ⭐️ 核心 SSH 实现
用途: SSH 连接管理的主要服务
核心类: SSHServiceImpl
关键方法:
- connect(config) - 建立 SSH 连接
- shell(sessionId, termConfig) - 打开 shell
- exec(sessionId, command) - 执行命令
- close(sessionId) - 关闭连接

依赖:
- ssh2 库 (SSH 协议实现)
- ConnectionPool (管理多个连接)
- ConnectionLogger (记录连接事件)
- AlgorithmCapture (捕获 SSH 算法协商)
重要: SSH 连接的核心实现

📄 /app/services/ssh/connection-pool.ts
用途: SSH 连接池管理
核心类: ConnectionPool
功能: 管理活跃的 SSH 连接

📄 /app/services/ssh/connection-handlers.ts
用途: SSH 连接事件处理
功能: 注册 SSH 连接生命周期事件处理

📄 /app/services/ssh/exec-command.ts
用途: SSH 远程命令执行
核心函数: executeSshCommand()
功能: 在远程 SSH 上执行命令

📄 /app/services/ssh/algorithm-capture.ts & analyzer.ts
用途: SSH 算法协商分析
功能:
- 捕获客户端和服务器支持的算法

- 生成诊断信息

📄 /app/services/terminal/terminal-service.ts
用途: 终端生命周期管理
核心类: TerminalService
关键方法:
- create(config) - 创建新终端
- resize(id, dimensions) - 调整大小

📄 /app/services/sftp/sftp-service.ts

📄 /app/services/auth/auth-service.ts

📄 /app/services/host-key/host-key-service.ts

参考数据流图
═════════════════════════════════════════════════════════════════════════════════

HTTP 请求流:
用户请求 → Express 路由 → routes-v2.ts → connectionHandler.ts
→ 读取 HTML → html-transformer → 注入配置 → 返回给浏览器

WebSocket 连接流:
Browser → Socket.IO 连接 → socket-v2.ts → ServiceSocketAdapter
→ 各子处理器 (auth, terminal, sftp, etc.)

认证流:
credentials → auth-pipeline → auth-providers → ssh-service.connect()
→ SSH 连接建立

终端数据流:
Browser input → 'data' event → ServiceSocketTerminal.handleData()
→ SSH shell.stdin → SSH server
→ SSH server output → SSH shell.stdout event
→ ServiceSocketTerminal → 'data' event → Browser display

- Telnet: /telnet/assets/*

- SSH: /ssh
- Telnet: /telnet

认证方法可配置:
- allowedAuthMethods: string[]  (在配置中定义)
