完整连接和数据流示例
═══════════════════════════════════════════════════════════════════════════════

Step 1: 用户访问页面
────────────────────
GET http://webssh.com/ssh?host=server.com
│
▼
GET /ssh?host=server.com
(app/routes/routes-v2.ts)
│
▼
Read client.htm template
(app/connectionHandler.ts)
│
▼
Inject config: {
socket: { url: ws://..., path: /socket.io },
autoConnect: false
}
│
▼
Return HTML to browser


Step 2: 客户端建立 WebSocket 连接
──────────────────────────────────
Browser loads HTML & JS
│
▼
Connect to WebSocket
(ws://webssh.com/socket.io)
│
▼
Socket 连接事件触发
(socket-v2.ts: io.on('connection', ...))
│
▼
创建 ServiceSocketAdapter
│
▼
checkInitialAuth()
│
├─ 无认证? → requestAuthentication()
│           (emit 'authentication' with action: 'request_auth')
│
└─ 有认证? → 自动连接
handleAuthentication(creds)


Step 3: 认证流程
────────────────
用户在表单中输入凭证
│
▼
Client emit 'authenticate' with credentials
│
▼
ServiceSocketAuthentication.handleAuthentication()
│
▼
UnifiedAuthPipeline.authenticate(credentials)
│
▼
SSHServiceImpl.connect(sshConfig)
│
├─ 成功 ──→ emit 'authentication' (success)
│          emit 'ready'
│          State: sessionId, connectionId set
│
└─ 失败 ──→ emit 'connection-error'
Reason: network/timeout/auth/algorithm
(含 debug info 如算法分析)


Step 4: 终端打开
────────────────
用户打开终端或 shell
│
▼
Client emit 'terminal' with { cols: 80, rows: 24, term: 'xterm-256color' }
│
▼
ServiceSocketTerminal.handleTerminal()
│
▼
SSHServiceImpl.shell(sessionId, termConfig)
│
├─ 创建 PTY
├─ 打开 shell 流
└─ 设置数据处理
│
▼
双向数据流建立:

             SSH ──→ WebSocket ──→ Browser
             └─ pipe shell.stdout to socket
             └─ emit 'data' events

             Browser ──→ WebSocket ──→ SSH
             └─ socket.on('data')
             └─ write to shell.stdin


Step 5: 终端交互
────────────────
用户在终端中输入命令
│
▼
Client emit 'data' with input bytes
│
▼
ServiceSocketTerminal.handleData(data)
│
▼
Write to SSH shell stream
│
▼
SSH server processes command
│
▼
Output received by client
│
▼
Server emit 'data' event with output
│
▼
Browser receives & displays output

数据流向总结
═══════════════════════════════════════════════════════════════════════════════

命令行方向:
Browser Terminal Input
↓
WebSocket 'data' event
↓
ServiceSocketTerminal.handleData()
↓
SSH shell stream.stdin
↓
Remote SSH Server
↓
Command Execution


结果返回方向:
Remote SSH Server Output
↓
SSH shell stream.stdout (监听中)
↓
EventEmitter 'data' 事件
↓
Socket 'data' 事件
↓
WebSocket 传输
↓
Browser Terminal Display
